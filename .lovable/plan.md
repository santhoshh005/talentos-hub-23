# Resume Analyzer — PDF Export with Visual Graphs

Replace the current plain-text `.txt` download in the Resume Analyzer with a full multi-page PDF that mirrors everything shown on the results screen, including visual charts.

## What the PDF will contain

Every section currently visible in the analyzer workspace, laid out across pages:

1. **Cover / Header** — TalentOS branding, candidate name, date, overall match score badge, verdict.
2. **Candidate profile** — name, email, phone, location, experience, current company, education.
3. **Match overview (visual)** — donut/ring chart for overall score + horizontal bar chart for the 5 category scores (Technical, Experience, Education, Communication, Culture Fit).
4. **Skills breakdown (visual)** — chips/lists for Matching, Additional, Missing skills + a stacked bar comparing counts.
5. **AI insights** — summary, strengths, weaknesses, resume improvements, hiring recommendation.
6. **Interview questions** — technical, HR, scenario.
7. **Resume scorecard (visual)** — bar chart for the 7 scorecard metrics (ATS, keywords, formatting, etc.).
8. **Footer on every page** — "Generated by TalentOS • talentos.ai" + page numbers.

Styling matches the app: dark surfaces optional, but default to a clean light print-friendly theme with the TalentOS blue/cyan accents so it prints well and reads well on screen.

## How it will work

- Add `jspdf` + `jspdf-autotable` (pure JS, works client-side, no native deps).
- Render the charts to canvas using a lightweight approach: draw the donut, bars, and score rings directly on an offscreen `<canvas>` with the Canvas 2D API (no extra chart lib needed — keeps bundle small and avoids SSR issues), then embed each as a PNG via `pdf.addImage`.
- New file `src/lib/resume-report-pdf.ts` exports `generateResumeReportPdf(parsed, analysis)` returning a `jsPDF` instance; keeps all layout logic isolated and testable.
- `ResumeAnalyzerModal.tsx` `downloadReport` handler becomes async: calls the generator, then `pdf.save('talentos-resume-analysis-<candidate>.pdf')`. Shows a toast + spinner while generating.
- Keep Copy and Share actions as-is (still use text). Only the Download button changes to PDF.

## Technical notes

- Client-only module (imports `jspdf`); safe because it's invoked from a button handler in a client component.
- Pagination handled by tracking a running `y` cursor and calling `pdf.addPage()` when a section would overflow; each section starts with a header helper for consistency.
- Long lists (skills, questions) use `pdf.splitTextToSize` for wrapping.
- Charts drawn at 2× resolution then scaled to keep them crisp in the PDF.
